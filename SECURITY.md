# Security Policy

## Supported Versions
We provide continuous automated builds on the latest release tags:

| Version Tag | Supported |
| --- | --- |
| `latest` | :white_check_mark: |
| `nodes-cuda128-sm120` | :white_check_mark: |
| `full-cuda128-sm120` | :white_check_mark: |
| `base-cuda128-sm120` | :white_check_mark: |
| `blender-worker` | :white_check_mark: |
| `v0.2.2-cuda128-sm120` | :white_check_mark: |
| Older date-specific tags | :x: (Archival only) |

## Reporting a Vulnerability
If you discover a security vulnerability within this repository or container configuration, please report it via private GitHub Advisory or by opening an issue for non-sensitive bugs.

For security vulnerabilities in upstream projects:
* ComfyUI core: Please report to [ComfyUI Security](https://github.com/comfyanonymous/ComfyUI/security).
* Base runtime: Please report to [ai-dock](https://github.com/ai-dock/comfyui/security).
